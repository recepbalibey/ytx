Clean transcript: Markdown without timestamps, ready for AI tools. Recommended
No extra format selection is required. YTX always creates a clean Markdown transcript. For playlists/channels in flat mode, YTX also creates output.md with all completed transcripts combined.
Automatic: YTX first tries YouTube without browser authentication. Select a browser to use your signed-in session when YouTube requires sign-in. YTX does not store or export browser cookies.
Flat: one file per video in the source folder. Structured: per-video directories.
